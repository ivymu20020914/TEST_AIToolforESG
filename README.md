# 公司内部 AI 工具中心 · 静态原型

一个无需后端、数据库或 API 的纯静态单页原型，适合放在 GitHub Pages 上进行早期演示。

## 原型包含

- 六类可点击工具：ESG 同业报告对标、产业链 / 行业调研、Word 格式转换、PPT 模板生成、专业 AI 助手、项目空间 / 团队记忆
- 模拟表单、模拟文件选择和固定假数据结果
- 权限与费用统计的视觉入口
- 正式版文件上传、处理、存储、下载流程说明
- 响应式布局，可在电脑和手机浏览器中查看

## 本地查看

直接双击 `index.html` 即可查看。为了让路由和资源加载方式更接近 GitHub Pages，也可以在本目录启动任意静态文件服务器。

### 本机 ESG 指标表生成

通过绑定到本机地址的静态服务器打开 `#/indicators`。字典文件位于 `local_data/esg-indicators.json`，已配置为忽略提交。更新字典时，在安装了 openpyxl 的 Python 环境中运行 `python scripts/import-indicators.py <指标字典.xlsx>`，然后刷新网页。

多选对标要求后生成，常规项始终纳入。可在预览选择已整理的统计口径，并下载可用 Excel 打开的 CSV。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，不要放真实客户文件或密钥。
2. 将本目录中的 `index.html`、`styles.css`、`app.js`、`indicators.js`、`.nojekyll` 和 `README.md` 提交到默认分支。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择默认分支与 **/(root)**，点击 **Save**。
6. 等待 GitHub 显示站点地址后访问。后续只需修改并提交这些静态文件。

## 安全边界

- 当前文件选择框只显示本机文件名，不会读取、上传或保存文件。
- 演示工具使用虚构结果。指标表根据通用字典生成，在线试用使用 data 目录中的快照。
- 不要把 API Key、账号密码、客户资料、个人信息或保密文件提交到公开仓库。
- 正式版应采用后端鉴权和私有对象存储，并实现权限隔离、访问日志、传输加密和生命周期清理。

## 正式版文件流向

浏览器选择本机文件 → 后端鉴权或签发上传凭证 → 私有 OSS 保存原文件 → 任务服务按权限读取和处理 → 结果写回私有 OSS 或服务器临时目录 → 用户下载到本机。

OSS 是对象存储，不是服务器内存。正式版需根据资料敏感程度决定存储区域、保留期限、加密、备份与删除策略。

## 在线指标表试用

访问 [ESG 指标表生成](https://ivymu20020914.github.io/TEST_AIToolforESG/#/indicators)，可选择标准、筛选指标、调整口径并导出 CSV。定义修改和勾选保留在本次页面中，刷新后恢复字典快照。

公开试用数据包含通用指标框架及已核对的标准中文释义，保存在 `data/esg-indicators.json`。项目化定义、历史口径、原始分类及内部备注保存在本机数据中。使用 `python scripts/import-indicators.py <指标字典.xlsx> --publish-snapshot` 更新试用快照。当前提供首批标准映射，行业适用性及具体项目口径需要项目经理确认。
